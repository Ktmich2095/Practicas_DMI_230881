##  Objetivo del repositorio

Este repositorio tiene como finalidad almacenar y documentar las prácticas desarrolladas durante la materia de **Desarrollo Móvil Integral**, aplicando los conocimientos adquiridos sobre desarrollo de aplicaciones móviles utilizando el framework **Flutter**.

Durante las prácticas se trabajará con diferentes conceptos y herramientas para la construcción de interfaces y aplicaciones móviles funcionales.

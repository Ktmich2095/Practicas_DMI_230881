# Grabaciones de pantallas de carga

[Inventario y ejemplos de inserción](../README.md)

Pendientes: `splash-normal.mp4`, `splash-halloween.mp4`, `splash-navidad.mp4` y
`splash-san-valentin.mp4`.

Graba un inicio real por temática, incluida la animación Flutter, su bienvenida
sonora y la transición al feed. Comprueba que el audio suene una sola vez y se
detenga al terminar la carga. El splash nativo Android no se altera.

Las pistas de la aplicación permanecen en `assets/sounds/`; aquí van las
grabaciones MP4 que prueban el comportamiento, no las pistas MP3.
